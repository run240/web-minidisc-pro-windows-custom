Web MiniDisc Pro 1.5.4 Windows Custom - 테스트 배포 안내
========================================================

1. 실행 방법
- ZIP 파일을 먼저 완전히 압축 해제하세요.
- 압축을 푼 폴더의 "Web MiniDisc Pro.exe"를 실행하세요.
- MiniDisc 기기를 연결한 뒤 NetMD 또는 Hi-MD 모드를 선택하세요.

2. 서명되지 않은 테스트 버전 주의
- 이 파일은 아직 코드 서명이 적용되지 않은 테스트 빌드입니다.
- Windows SmartScreen 또는 Smart App Control에서 실행을 차단할 수 있습니다.
- 파일을 직접 전달받았고 출처를 신뢰할 수 있는 경우에만 테스트하세요.
- 이 프로그램 하나를 실행하기 위해 Windows 보안 기능 전체를 끄는 것은 권장하지 않습니다.
- Smart App Control 정책에 따라 일부 PC에서는 서명 완료 전까지 실행할 수 없습니다.

3. MD Squirrel
- 원본 음원은 변경하지 않고 원본 폴더 옆에 "[English]" 복사본 폴더를 만듭니다.
- Apple 미국 음악 검색을 이용해 한글·일본어 제목의 영문 후보를 찾습니다.
- 확인된 공식 영문 아티스트명은 같은 아티스트의 다른 곡에도 함께 적용합니다.
- 기존 영문·로마자 제목은 그대로 유지합니다.
- 후보의 재생시간 차이가 크거나 동아시아 문자가 남으면 자동 확정하지 않습니다.
- "웹에서 직접 찾기" 결과는 참고용이며, 공식 음원 정보를 확인한 뒤 직접 수정하세요.
- 검색 기능을 사용하려면 인터넷 연결이 필요합니다.

4. 테스트 시 확인할 항목
- 포터블 NetMD/데크/Hi-MD 기기의 WinUSB 드라이버 준비 여부
- 드라이버 설치 중 Windows에서 WinUSB가 확인되면 3분을 기다리지 않고 연결을 계속하는지 확인
- Windows 밝은 모드에서도 디스크 제목과 트랙 목록 글자가 밝게 보이는지 확인
- NetMD와 Hi-MD 모드 전환 및 자동 재연결
- 프로그램 재실행 후 창 위치와 자동 연결
- 녹음, 취소, 강제 종료 후 재연결
- 전송 정지 경고에서 "진단 정보 복사"가 1~2초 안에 완료되는지 확인
- MD Squirrel의 폴더 검색, 후보 적용, 영문 복사본 생성

5. 문제 제보 시 함께 알려주면 좋은 정보
- Windows 버전
- MiniDisc 기기 모델명
- 사용한 디스크 종류와 모드(NetMD/Hi-MD)
- 오류가 발생하기 직전의 작업 순서
- 오류 화면 캡처와 화면에 표시된 진단 문구

테스트 버전이므로 중요한 디스크는 백업 후 사용해 주세요.
